# Plans

This folder holds saved plans — one file per plan — kept in the repo so the
decisions, scope, and status of each piece of work are recorded and reviewable.

## Convention

- **One file per plan**, named after its topic, e.g.
  `robot-behavior-upgrades-7-features.md`.
- Keep the plan even after the work is done — it is the record of *why* and
  *how* a change was made.
- Update the plan's status as work progresses (e.g. a `## Status` section) rather
  than deleting it.
